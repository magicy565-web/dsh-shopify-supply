# 产品发布工作台：前端验收

入口：`/#projects` 或 `/#publish`。工作室草稿可从项目中心导入，原草稿仍保留。

## 本次范围

- 独立项目草稿与编辑步骤，浏览器本地保存及刷新恢复。
- 七步内容准备：基本信息、媒体、故事、进展计划、参与方式、团队风险、预览提交。
- 图片上传、排序、移除和封面选择；HTTPS 视频链接；桌面/手机宽度预览。
- 明确标注的模拟审核：提交、撤回、退回意见、重新提交、通过、本地发布。
- 新修订与已发布快照分别保存；重新审核发布后才替换快照。
- 项目中心分类、草稿归档恢复，发布内容连接发现页、详情页、供应链工作台。

## 已执行检查

- TypeScript 检查通过，Next.js 生产构建通过。
- 浏览器创建测试项目，填写七步内容，刷新恢复到预览步骤。
- 模拟提交、退回意见、重新提交、通过、本地发布，检查详情包含团队、风险和计划。
- 修改修订稿名称，确认发布页仍显示原名称。
- 创建第二份草稿，验证不继承第一份内容；缺少必填项时不能继续；草稿归档。
- 检查窄屏项目中心布局。
